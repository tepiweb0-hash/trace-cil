# TRACE CIL V10.3 — Visuals Update

This update adds actual visual presentation to the investigation experience while keeping the beginner-friendly game flow from V10.2.

## Added
- 8 reusable SVG scene illustrations under `assets/`
- visual thumbnails on case cards
- illustrated dossier panel on every case header
- overview gallery strip inside each case
- visual thumbnails for evidence locker entries
- visual thumbnails for pinned evidence on the board
- richer desk landing page with case preview visuals

## Notes
- The visuals are thematic and atmosphere-driven so they can scale across all 100 cases.
- They are intentionally beginner-friendly and do not hide important text-based evidence.
- Existing C001–C100 data and logic remain intact.
